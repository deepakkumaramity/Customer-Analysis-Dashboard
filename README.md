## 📌 Project Overview

💡 This project focuses on analyzing **customer purchasing behavior** using **Python + SQL** to generate meaningful business insights.

👉 It helps answer:

* Who are the top customers?
* Which customers generate maximum revenue?
* How to improve customer retention?

---

## 🎯 Objectives

✅ Revenue Calculation
✅ Customer Segmentation
✅ Top Customers Identification
✅ Repeat Customers Analysis
✅ Business Insights Generation

---
